# Онлайн-анкета пассажиров пригородных поездов (АО «СЗППК»)

## Файлы
- `index.html` — анкета для пассажира (9 шагов, удобно с телефона, черновик хранится в браузере).
- `server.py` — приём анкет (SQLite), сводка и выгрузка. Нужен только Python 3; для .xlsx — openpyxl.

## Запуск
```
ADMIN_TOKEN=<секрет> PORT=8090 python server.py
```
- Анкета: `http://<сервер>:8090/` — эту ссылку размещают на сайте или в QR-коде в вагоне.
- Сводка: `/admin?token=<секрет>` — число анкет, индекс и NPS по кварталам, сравнение с планом.
- Выгрузка: `/admin/export.xlsx?token=<секрет>&year=2027&q=1` (или `.csv`).

Для публичной ссылки нужен HTTPS: поставить nginx перед сервером и передавать `X-Real-IP`.

## Как перенести данные в файл волны
Столбцы выгрузки идут в том же порядке, что и столбцы B…DL листа «База оценок».
Строки данных копируются начиная с ячейки **B19**, затем: Данные → Обновить всё.
Два последних столбца выгрузки («Дата заполнения», «Метод») служебные, их не вставляют.

## Логика переходов в анкете
- Способ покупки билета: касса/агентство → оценки кассы (столбцы 16–20);
  терминал/сайт/приложение → оценки онлайн-покупки (21–25); «в поезде»/«другое» → блок пропускается.
- «Оставляли обращение?» Да → каналы (83–87, оценивается только отмеченный канал) → тема (88);
  если отмечен ЦПК → оценки ЦПК (89–92) и «решён ли вопрос» (93).
- Номер поезда на 7… → появляются поля «номер вагона» и «класс обслуживания».
- Приоритеты 1–9 расставляются нажатием по порядку, без повторов. «Что изменить» — от 1 до 3 пунктов.
- Для услуг с пометкой «если пользовались» есть вариант «не пользовался» (п. 5 Методики); такой ответ в выгрузку не попадает.

## Индекс
Считается так же, как ветка «ППК» формулы L37 листа «Отчет». Проверено на волнах 2026 года:
85,605 / 85,819 / 85,530 / 85,492 — результаты совпадают с Excel.

## Ограничения
По п. 4.3 Методики новый метод опроса нужно согласовать с Департаментом пассажирских перевозок.
В первый год онлайн-анкеты учитываются отдельно от традиционного опроса.
